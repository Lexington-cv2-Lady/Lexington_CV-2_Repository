# Lexington_CV-2_Repository

Lexington 的卫月（Dalamud）插件清单库。**添加本库地址后，插件列表自动出现以下全部插件；以后新增插件也会自动出现，无需再改配置。**

## 当前收录

| 插件 | 说明 |
|---|---|
| [FFXIV_penumbra的模组汉化插件](https://github.com/Lexington-cv2-Lady/FFXIV_Penumbra_Mod_Chinese_Localization_Plugin) | 把 Penumbra 模组的英文选项与描述批量汉化为简体中文并写回，游戏内即时生效 |

## 添加方式

卫月设置 →「实验性」→「自定义插件仓库」，添加以下任一地址：

**主地址**
```
https://raw.githubusercontent.com/Lexington-cv2-Lady/Lexington_CV-2_Repository/main/plugin_repo.json
```

**镜像**（主地址加载慢时用）
```
https://cdn.jsdmirror.com/gh/Lexington-cv2-Lady/Lexington_CV-2_Repository@main/plugin_repo.json
```

然后在插件安装器中搜索插件名安装。

## 说明

- 本库只存插件清单（plugin_repo.json）；安装包由各插件源码仓库的 Releases 提供，链接写在清单的 DownloadLink 中。
- 旧地址（源码仓库内的 plugin_repo.json）内容与本库保持同步，老用户无需迁移。
